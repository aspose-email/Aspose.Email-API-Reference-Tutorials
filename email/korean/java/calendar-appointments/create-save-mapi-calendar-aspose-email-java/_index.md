# Aspose.Email – Java를 사용하여 Outlook 캘린더 PST 내보내기

## 소개

Java 애플리케이션에서 캘린더 자동화를 간소화하고 **Outlook 캘린더 PST** 파일을 내보내고 싶으신가요? **Aspose.Email for Java**를 사용하면 **create MAPI calendar Java** 항목을 **생성**하고, 반복 패턴을 정의하며, 참석자를 추가하고, **save calendar to PST**를 몇 줄의 코드만으로 수행할 수 있습니다. 이 튜토리얼은 라이브러리 설정부터 배포 가능한 완전한 캘린더 항목 생성까지 전체 과정을 안내합니다.

### 배울 내용
- Aspose.Email를 사용하여 **create MAPI calendar Java** 이벤트를 만드는 방법.  
- 일일, 주간 또는 사용자 정의 반복 패턴 구성.

## 구현 가이드

설정이 완료되었으니, **create MAPI calendar Java**와 **save calendar to PST**를 수행해 보겠습니다.

### 반복이 있는 MAPI 캘린더 만들기

#### 개요

캘린더 이벤트를 만들고, 일일 반복을 적용하며, 참석자를 추가하고, 마지막으로 PST 파일에 저장합니다.

#### 단계별 구현

1. **날짜 및 반복 패턴 초기화**  

   `MapiCalendarEventRecurrence`는 캘린더 항목의 반복 세부 정보를 저장하는 클래스입니다.  
   `MapiCalendarDailyRecurrencePattern`은 간단한 일일 반복 일정을 정의합니다.  

   먼저 시작 시간을 정의하고 일일 반복을 설정합니다:

   ```java
   import java.util.Date;

   // Add hours to current date to get the start time
   Date startDate = addHours(new Date(), 12);

   MapiCalendarEventRecurrence recurrence = new MapiCalendarEventRecurrence();
   recurrence.setRecurrencePattern(new MapiCalendarDailyRecurrencePattern());
   ```

2. **수신자 설정**  

   `MapiRecipientCollection`은 회의에 초대된 사람들의 목록을 나타냅니다.  
   `MAPI_TO`는 수신자를 주요 참석자로 표시하는 플래그입니다.  

   회의 초대를 받아야 할 사람들을 추가합니다:

   ```java
   import com.aspose.email.MapiRecipientCollection;
   import com.aspose.email.MapiRecipientType;

   MapiRecipientCollection recColl = new MapiRecipientCollection();
   recColl.add("recipient@gmail.com", "Attendee Name", MapiRecipientType.MAPI_TO);
   ```

3. **MAPI 캘린더 항목 만들기**  

   `MapiMessage` 클래스(여기서는 캘린더 객체로 사용)는 조직자, 제목, 위치, 시작/종료 시간, 설명, 수신자 목록 및 반복과 같은 모든 이벤트 속성을 캡슐화합니다.  

   모든 필요한 세부 정보를 포함하여 캘린더 객체를 구축합니다:

   ```java
   import com.aspose.email.MapiCalendar;

   MapiCalendar calendar = new MapiCalendar(
       "Organizer Name", 
       "Meeting Subject", 
       "Meeting Location", 
       startDate, 
       addHours(startDate, 1), // End time is one hour after start
       "Event Description",
       recColl,
       recurrence
   );
   ```

4. **PST 파일에 저장**  

   `PersonalStorage`는 PST 파일을 생성하고 조작하기 위한 Aspose.Email의 최상위 API입니다.  
   `addMapiMessageItem`은 지정된 폴더에 MAPI 메시지(캘린더 항목 포함)를 삽입합니다.  

   마지막으로 **saving calendar to PST**로 캘린더를 지속시킵니다:

   ```java
   import com.aspose.email.PersonalStorage;
   import com.aspose.email.FolderInfo;
   import com.aspose.email.StandardIpmFolder;

   PersonalStorage pst = PersonalStorage.create("calendar.pst", 0);
   FolderInfo calendarFolder = pst.createPredefinedFolder("Calendar", StandardIpmFolder.CALendars);

   // Save the MAPI Calendar item
   calendarFolder.addMapiMessageItem(calendar);
   ```

1. **Automated meeting scheduling** – 수동 작업 없이 프로젝트 팀을 위한 반복 회의 초대를 생성합니다.  
2. **Event management platforms** – 회의 세션을 Outlook 호환 캘린더 항목으로 내보냅니다.

## FAQ 섹션

### Q: 주간 반복 패턴을 만들 수 있나요?
- **A**: 예! `MapiCalendarWeeklyRecurrencePattern`을 사용하여 주간 반복을 정의합니다.

### Q: 이벤트 반복에서 예외를 어떻게 처리합니까?
- **A**: 패턴에서 벗어나는 날짜를 지정하려면 반복 객체에서 `setExceptions()`를 호출하십시오.

### Q: 기존 캘린더 항목을 업데이트할 수 있나요?
- **A**: 물론입니다. PST에서 항목을 로드하고 속성을 수정한 뒤 다시 저장하십시오.

### Q: PST 파일을 암호화할 수 있나요?
- **A**: 예, Aspose.Email를 사용하면 PST를 생성할 때 `PersonalStorage`에 비밀번호를 설정할 수 있습니다.

### Q: 캘린더 이벤트에 첨부 파일을 추가해야 하면 어떻게 합니까?
- **A**: 저장하기 전에 `calendar.getAttachments().addFileAttachment("path/to/file")`를 사용하십시오.
