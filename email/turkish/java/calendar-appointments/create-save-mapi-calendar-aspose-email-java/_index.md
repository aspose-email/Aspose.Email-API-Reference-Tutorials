## Uygulama Rehberi

Artık kurulum tamam, **create MAPI calendar Java** ve **save calendar to PST** yapalım.

### Yinelemeli MAPI Takvim Oluşturma

#### Genel Bakış

Bir takvim etkinliği oluşturacağız, günlük yineleme uygulayacağız, katılımcılar ekleyeceğiz ve sonunda bir PST dosyasına kaydedeceğiz.

#### Adım‑adım Uygulama

1. **Tarih ve yineleme desenini başlat**  

   `MapiCalendarEventRecurrence`, bir takvim öğesinin yineleme detaylarını saklayan sınıftır.  
   `MapiCalendarDailyRecurrencePattern`, basit bir günlük tekrar programı tanımlar.  

   İlk olarak, başlangıç zamanını tanımlayın ve günlük bir yineleme ayarlayın:

   ```java
   import java.util.Date;

   // Add hours to current date to get the start time
   Date startDate = addHours(new Date(), 12);

   MapiCalendarEventRecurrence recurrence = new MapiCalendarEventRecurrence();
   recurrence.setRecurrencePattern(new MapiCalendarDailyRecurrencePattern());
   ```

2. **Alıcıları ayarla**  

   `MapiRecipientCollection`, toplantıya davet edilen kişilerin listesini temsil eder.  
   `MAPI_TO`, bir alıcıyı birincil katılımcı olarak işaretleyen bayraktır.  

   Toplantı davetini alması gereken kişileri ekleyin:

   ```java
   import com.aspose.email.MapiRecipientCollection;
   import com.aspose.email.MapiRecipientType;

   MapiRecipientCollection recColl = new MapiRecipientCollection();
   recColl.add("recipient@gmail.com", "Attendee Name", MapiRecipientType.MAPI_TO);
   ```

3. **MAPI takvim öğesini oluştur**  

   `MapiMessage` sınıfı (burada takvim nesnesi olarak kullanılmıştır), organizatör, konu, konum, başlangıç/bitiş zamanları, açıklama, alıcı listesi ve yineleme gibi tüm etkinlik özelliklerini kapsar.  

   Gerekli tüm detaylarla takvim nesnesini oluşturun:

   ```java
   import com.aspose.email.MapiCalendar;

   MapiCalendar calendar = new MapiCalendar(
       "Organizer Name", 
       "Meeting Subject", 
       "Meeting Location", 
       startDate, 
       addHours(startDate, 1), // End time is one hour after start
       "Event Description",
       recColl,
       recurrence
   );
   ```

4. **PST dosyasına kaydet**  

   `PersonalStorage`, PST dosyaları oluşturmak ve manipüle etmek için Aspose.Email'in üst‑seviye API'sidir.  
   `addMapiMessageItem`, belirtilen bir klasöre bir MAPI mesajı (takvim öğeleri dahil) ekler.  

   Son olarak, takvimi **saving calendar to PST** ile kalıcı hale getirin:

   ```java
   import com.aspose.email.PersonalStorage;
   import com.aspose.email.FolderInfo;
   import com.aspose.email.StandardIpmFolder;

   PersonalStorage pst = PersonalStorage.create("calendar.pst", 0);
   FolderInfo calendarFolder = pst.createPredefinedFolder("Calendar", StandardIpmFolder.CALendars);

   // Save the MAPI Calendar item
   calendarFolder.addMapiMessageItem(calendar);
   ```

### S: Haftalık yineleme desenleri oluşturabilir miyim?
- **A**: Evet! Haftalık tekrarları tanımlamak için `MapiCalendarWeeklyRecurrencePattern` kullanın.

### S: Etkinlik yinelemesinde istisnaları nasıl yönetirim?
- **A**: Desenden sapma gösteren tarihleri belirtmek için yineleme nesnesinde `setExceptions()` çağırın.

### S: Mevcut bir takvim öğesini güncellemek mümkün mü?
- **A**: Kesinlikle. Öğeyi PST'den yükleyin, özelliklerini değiştirin ve tekrar kaydedin.

### S: PST dosyasını şifreleyebilir miyim?
- **A**: Evet, Aspose.Email PST oluştururken `PersonalStorage` üzerine bir şifre ayarlamanıza izin verir.

### S: Takvim etkinliğine ek dosya eklemem gerekirse?
- **A**: Kaydetmeden önce `calendar.getAttachments().addFileAttachment("path/to/file")` kullanın.
