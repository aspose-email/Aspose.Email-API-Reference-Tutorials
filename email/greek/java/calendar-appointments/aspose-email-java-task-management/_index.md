# Πώς να καταγράψετε εργασίες με το Aspose.Email για Java

## Εισαγωγή

Στις σύγχρονες επιχειρήσεις, η αυτοματοποίηση της διαχείρισης εργασιών στο Microsoft Exchange μειώνει την χειροκίνητη προσπάθεια και βελτιώνει την ακρίβεια. Αυτό το σεμινάριο εξηγεί **πώς να καταγράψετε εργασίες** από ένα γραμματοκιβώτιο Exchange χρησιμοποιώντας το Aspose.Email για Java και δείχνει **πώς να φιλτράρετε εργασίες** κατά κατάσταση, ώστε να μπορείτε να δημιουργήσετε pipelines αναφοράς ή μηχανές συγχρονισμού χωρίς να αγγίζετε το Outlook. Θα δείτε τη απαιτούμενη ρύθμιση, τις ακριβείς κλήσεις API και συμβουλές βέλτιστων πρακτικών για απόδοση και αξιοπιστία.

## Γρήγορες απαντήσεις
- **Τι κάνει το “list exchange tasks java”;** Ανακτά εργασίες από ένα γραμματοκιβώτιο Exchange μέσω του Aspose.Email για Java.  
- **Ποια βιβλιοθήκη απαιτείται;** Aspose.Email for Java (έκδοση 25.4 ή νεότερη).  
- **Μπορώ να φιλτράρω εργασίες κατά κατάσταση;** Ναι—χρησιμοποιήστε το `ExchangeQueryBuilder` με το `TaskStatus`.  
- **Χρειάζομαι άδεια για ανάπτυξη;** Μια δωρεάν δοκιμή λειτουργεί για δοκιμές· απαιτείται πλήρης άδεια για παραγωγή.  
- **Ποια έκδοση Java υποστηρίζεται;** Συνιστάται Java 16 ή νεότερη.

## Τι είναι το “list exchange tasks java”;
Η καταγραφή εργασιών Exchange με Java σημαίνει προγραμματιστική σύνδεση σε έναν Exchange Server, λήψη της συλλογής εργασιών και προαιρετικό φιλτράρισμα. Αυτό επιτρέπει αυτοματοποίηση όπως μαζικές ενημερώσεις, αναφορές ή ενεργοποιήσεις ροής εργασίας χωρίς χειροκίνητη αλληλεπίδραση με το Outlook. Μπορεί να χρησιμοποιηθεί για τη δημιουργία αποθεμάτων εργασιών, συγχρονισμό με εργαλεία διαχείρισης έργων ή τροφοδοσία δεδομένων σε pipelines ανάλυσης, μειώνοντας έτσι την χειροκίνητη προσπάθεια και εξασφαλίζοντας συνέπεια μεταξύ των συστημάτων.

## Γιατί να φιλτράρετε εργασίες κατά κατάσταση;
Το φιλτράρισμα εργασιών κατά κατάσταση σας επιτρέπει να απομονώσετε την εργασία που είναι σημαντική αυτή τη στιγμή—π.χ., να εμφανίσετε μόνο ανοιχτά στοιχεία για ένα καθημερινό ταμπλό, ή να εξάγετε ολοκληρωμένες εργασίες για μια αναφορά κλεισίματος. Μειώνει τον όγκο των δεδομένων, επιταχύνει την επεξεργασία και επιτρέπει στα συστήματα downstream να αντιδρούν μόνο σε σχετικές αλλαγές.

Για να ενσωματώσετε τη βιβλιοθήκη Aspose.Email στο έργο σας, προσθέστε αυτήν την εξάρτηση στο `pom.xml` εάν χρησιμοποιείτε Maven:

```xml
<dependency>
    <groupId>com.aspose</groupId>
    <artifactId>aspose-email</artifactId>
    <version>25.4</version>
    <classifier>jdk16</classifier>
</dependency>
```

### Βήματα απόκτησης άδειας

1. **Δωρεάν δοκιμή** – Ξεκινήστε με μια δωρεάν δοκιμή για να εξερευνήσετε τις δυνατότητες.  
2. **Προσωρινή άδεια** – Αιτηθείτε μια εκτεταμένη άδεια δοκιμής εάν χρειάζεται.  
3. **Αγορά** – Σκεφτείτε την αγορά πλήρους άδειας μετά την αξιολόγηση της βιβλιοθήκης.

Με το περιβάλλον σας ρυθμισμένο και μια άδεια στα χέρια, αρχικοποιήστε τη βιβλιοθήκη ως εξής:

```java
String mailboxUri = "https://ex2010/exchangeews/exchange.asmx";
String username = "test.exchange";
String password = "pwd";
String domain = "ex2010.local";

NetworkCredential credentials = new NetworkCredential(username, password, domain);
IEWSClient client = EWSClient.getEWSClient(mailboxUri, credentials);
```

Αυτό το απόσπασμα διαμορφώνει τον πελάτη Exchange με τα διαπιστευτήριά σας.

## Οδηγός υλοποίησης

### Αρχικοποίηση πελάτη exchange

`ExchangeClient` είναι η κύρια κλάση του Aspose.Email για σύνδεση σε διακομιστή Exchange. Διαχειρίζεται τον έλεγχο ταυτότητας, τη διαχείριση συνεδρίας και παρέχει πρόσβαση στους φακέλους του γραμματοκιβωτίου.

```java
String mailboxUri = "https://ex2010/exchangeews/exchange.asmx";
String username = "test.exchange";
String password = "pwd";
String domain = "ex2010.local";

NetworkCredential credentials = new NetworkCredential(username, password, domain);
IEWSClient client = EWSClient.getEWSClient(mailboxUri, credentials);
```

- **Parameters**:  
  - `mailboxUri`: Η διεύθυνση URL του τελικού σημείου του διακομιστή Exchange.  
  - `username`, `password`, `domain`: Διαπιστευτήρια για έλεγχο ταυτότητας.

### Λίστα όλων των εργασιών από διακομιστή exchange

`TaskCollection` αντιπροσωπεύει το σύνολο των εργασιών που αποθηκεύονται σε φάκελο γραμματοκιβωτίου. Η ανάκτησή του επιστρέφει κάθε στοιχείο εργασίας, ανεξάρτητα από την κατάσταση.

```java
client.setTimezoneId("Central Europe Standard Time");
TaskCollection taskCollection = client.listTasks(client.getMailboxInfo().getTasksUri());
int iTasksCount = taskCollection.size();
for (int i = 0; i < iTasksCount; i++) {
    ExchangeTask task = (ExchangeTask) taskCollection.get_Item(i);
    // Process each task
}
```

- **Parameters**:  
  - `setTimezoneId`: Διασφαλίζει ότι οι εργασίες εμφανίζονται στη σωστή τοπική ώρα.

### Ερώτημα και λίστα συγκεκριμένων εργασιών από διακομιστή exchange

`ExchangeQueryBuilder` δημιουργεί ερωτήματα στην πλευρά του διακομιστή, επιτρέποντάς σας να φιλτράρετε εργασίες ανά ιδιότητες όπως το `TaskStatus`. Αυτό είναι ο πυρήνας του **πώς να φιλτράρετε εργασίες**.

```java
Integer[] selectedStatuses = new Integer[]{
        ExchangeTaskStatus.Completed,
        ExchangeTaskStatus.InProgress
};

ExchangeQueryBuilder queryBuilder = new ExchangeQueryBuilder();
queryBuilder.getTaskStatus().in(Arrays.asList(selectedStatuses));
MailQuery query = queryBuilder.getQuery();

taskCollection = client.listTasks(client.getMailboxInfo().getTasksUri(), query);
iTasksCount = taskCollection.size();
for (int i = 0; i < iTasksCount; i++) {
    ExchangeTask task = (ExchangeTask) taskCollection.get_Item(i);
    // Process each queried task
}
```

- **Parameters**:  
  - `selectedStatuses`: Ένας πίνακας που καθορίζει ποιες καταστάσεις να συμπεριληφθούν στο σύνολο αποτελεσμάτων.

## Συνηθισμένα προβλήματα και λύσεις

| Issue | Likely cause | Solution |
|-------|--------------|----------|
| **Αποτυχία ελέγχου ταυτότητας** | Λανθασμένα διαπιστευτήρια ή domain | Επαληθεύστε τα `username`, `password` και `domain`; βεβαιωθείτε ότι η διεύθυνση URL του Exchange είναι προσβάσιμη. |
| **Δεν επιστράφηκαν εργασίες** | Λανθασμένο URI γραμματοκιβωτίου ή έλλειψη δικαιωμάτων | Επιβεβαιώστε ότι ο λογαριασμός υπηρεσίας μπορεί να έχει πρόσβαση στο φάκελο Tasks. |
