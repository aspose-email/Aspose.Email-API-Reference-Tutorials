## دليل التنفيذ

الآن بعد أن تم إعدادك، دعنا **ننشئ تقويم MAPI Java** و **نحفظ التقويم إلى PST**.

### إنشاء تقويم MAPI مع التكرار

#### نظرة عامة

سنقوم بإنشاء حدث تقويم، تطبيق تكرار يومي، إضافة الحضور، وأخيرًا تخزينه في ملف PST.

#### تنفيذ خطوة بخطوة

1. **تهيئة التاريخ ونمط التكرار**  

   `MapiCalendarEventRecurrence` هو الصنف الذي يخزن تفاصيل التكرار لعنصر التقويم.  
   `MapiCalendarDailyRecurrencePattern` يحدد جدول تكرار يومي بسيط.  

   أولاً، عرّف وقت البدء واضبط تكرارًا يوميًا:

   ```java
   import java.util.Date;

   // Add hours to current date to get the start time
   Date startDate = addHours(new Date(), 12);

   MapiCalendarEventRecurrence recurrence = new MapiCalendarEventRecurrence();
   recurrence.setRecurrencePattern(new MapiCalendarDailyRecurrencePattern());
   ```

2. **إعداد المستلمين**  

   `MapiRecipientCollection` يمثل قائمة الأشخاص المدعوين إلى الاجتماع.  
   `MAPI_TO` هو العلامة التي تحدد المستلم كحاضر أساسي.  

   أضف الأشخاص الذين يجب أن يتلقوا دعوة الاجتماع:

   ```java
   import com.aspose.email.MapiRecipientCollection;
   import com.aspose.email.MapiRecipientType;

   MapiRecipientCollection recColl = new MapiRecipientCollection();
   recColl.add("recipient@gmail.com", "Attendee Name", MapiRecipientType.MAPI_TO);
   ```

3. **إنشاء عنصر تقويم MAPI**  

   صنف `MapiMessage` (المستخدم هنا ككائن تقويم) يضم جميع خصائص الحدث مثل المنظم، الموضوع، الموقع، أوقات البدء/الانتهاء، الوصف، قائمة المستلمين، والتكرار.  

   بنِ عنصر التقويم بجميع التفاصيل المطلوبة:

   ```java
   import com.aspose.email.MapiCalendar;

   MapiCalendar calendar = new MapiCalendar(
       "Organizer Name", 
       "Meeting Subject", 
       "Meeting Location", 
       startDate, 
       addHours(startDate, 1), // End time is one hour after start
       "Event Description",
       recColl,
       recurrence
   );
   ```

4. **حفظ إلى ملف PST**  

   `PersonalStorage` هو API المستوى الأعلى في Aspose.Email لإنشاء ومعالجة ملفات PST.  
   `addMapiMessageItem` يدرج رسالة MAPI (بما في ذلك عناصر التقويم) في مجلد محدد.  

   أخيرًا، احفظ التقويم عن طريق **حفظ التقويم إلى PST**:

   ```java
   import com.aspose.email.PersonalStorage;
   import com.aspose.email.FolderInfo;
   import com.aspose.email.StandardIpmFolder;

   PersonalStorage pst = PersonalStorage.create("calendar.pst", 0);
   FolderInfo calendarFolder = pst.createPredefinedFolder("Calendar", StandardIpmFolder.CALendars);

   // Save the MAPI Calendar item
   calendarFolder.addMapiMessageItem(calendar);
   ```
