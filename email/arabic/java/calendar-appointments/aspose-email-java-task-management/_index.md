# كيفية سرد المهام باستخدام Aspose.Email للـ Java

## مقدمة

في المؤسسات الحديثة، يقلل أتمتة معالجة المهام على Microsoft Exchange من الجهد اليدوي ويحسن الدقة. يشرح هذا الدليل **كيفية سرد المهام** من صندوق بريد Exchange باستخدام Aspose.Email للـ Java ويظهر **كيفية تصفية المهام** حسب الحالة، بحيث يمكنك بناء خطوط تقارير أو محركات مزامنة دون الحاجة إلى Outlook. ستشاهد الإعداد المطلوب، واستدعاءات API الدقيقة، ونصائح أفضل الممارسات للأداء والموثوقية.

## إجابات سريعة
- **ما الذي يفعله “list exchange tasks java”?** يسترجع المهام من صندوق بريد Exchange عبر Aspose.Email للـ Java.  
- **ما المكتبة المطلوبة؟** Aspose.Email للـ Java (الإصدار 25.4 أو أحدث).  
- **هل يمكنني تصفية المهام حسب الحالة؟** نعم—استخدم `ExchangeQueryBuilder` مع `TaskStatus`.  
- **هل أحتاج إلى ترخيص للتطوير؟** النسخة التجريبية المجانية تعمل للاختبار؛ الترخيص الكامل مطلوب للإنتاج.  
- **ما نسخة Java المدعومة؟** يوصى بـ Java 16 أو أحدث.

## ما هو “list exchange tasks java”؟
تعني عملية سرد مهام Exchange باستخدام Java الاتصال برمجيًا بخادم Exchange، وجلب مجموعة المهام، وتصفيةها اختياريًا. يتيح ذلك الأتمتة مثل التحديثات الجماعية، وإعداد التقارير، أو تشغيل سير العمل دون تفاعل يدوي مع Outlook. يمكن استخدامه لإنشاء جرد للمهام، ومزامنة مع أدوات إدارة المشاريع، أو تغذية البيانات إلى خطوط تحليلية، مما يقلل الجهد اليدوي ويضمن التناسق عبر الأنظمة.

## لماذا تصفية المهام حسب الحالة؟
تسمح تصفية المهام حسب الحالة بعزل الأعمال المهمة حاليًا—مثلاً، إظهار العناصر المفتوحة فقط للوحة معلومات يومية، أو سحب المهام المكتملة لتقرير الإغلاق. يقلل ذلك من حجم البيانات، ويسرّع المعالجة، ويسمح للأنظمة اللاحقة بالتفاعل فقط مع التغييرات ذات الصلة.

## لماذا هذا مهم
استخدام Aspose.Email لـ **list exchange tasks java** يمنحك تحكمًا برمجيًا لا يمكن لواجهة Outlook أن تضاهيها. يمكنك أتمتة عمليات التنظيف المتكررة، دمج بيانات المهام في لوحات معلومات BI، أو تشغيل خدمات لاحقة—كل ذلك من قاعدة شفرة Java واحدة قابلة للصيانة. يدعم Aspose.Email **أكثر من 50 عملية Exchange** ويمكنه معالجة **مجموعات مهام مئات الصفحات** دون تحميل صندوق البريد بالكامل إلى الذاكرة، مما يضمن زمن استجابة منخفض واستخدامًا فعالًا للذاكرة.

## دليل التنفيذ

### تهيئة عميل Exchange
`ExchangeClient` هو الفئة الأساسية في Aspose.Email للاتصال بخادم Exchange. يتعامل مع المصادقة وإدارة الجلسة ويوفر الوصول إلى مجلدات صندوق البريد.

```java
String mailboxUri = "https://ex2010/exchangeews/exchange.asmx";
String username = "test.exchange";
String password = "pwd";
String domain = "ex2010.local";

NetworkCredential credentials = new NetworkCredential(username, password, domain);
IEWSClient client = EWSClient.getEWSClient(mailboxUri, credentials);
```

- **المعلمات**:  
  - `mailboxUri`: عنوان URL لنقطة النهاية لخادم Exchange الخاص بك.  
  - `username`، `password`، `domain`: بيانات الاعتماد للمصادقة.

### سرد جميع المهام من خادم Exchange
`TaskCollection` تمثل مجموعة المهام المخزنة في مجلد صندوق البريد. إرجاعها يعيد كل عنصر مهمة، بغض النظر عن الحالة.

```java
client.setTimezoneId("Central Europe Standard Time");
TaskCollection taskCollection = client.listTasks(client.getMailboxInfo().getTasksUri());
int iTasksCount = taskCollection.size();
for (int i = 0; i < iTasksCount; i++) {
    ExchangeTask task = (ExchangeTask) taskCollection.get_Item(i);
    // Process each task
}
```

- **المعلمات**:  
  - `setTimezoneId`: يضمن عرض المهام بالوقت المحلي الصحيح.

### استعلام وسرد مهام محددة من خادم Exchange
`ExchangeQueryBuilder` يبني استعلامات على مستوى الخادم، مما يتيح لك تصفية المهام حسب خصائص مثل `TaskStatus`. هذا هو جوهر **كيفية تصفية المهام**.

```java
Integer[] selectedStatuses = new Integer[]{
        ExchangeTaskStatus.Completed,
        ExchangeTaskStatus.InProgress
};

ExchangeQueryBuilder queryBuilder = new ExchangeQueryBuilder();
queryBuilder.getTaskStatus().in(Arrays.asList(selectedStatuses));
MailQuery query = queryBuilder.getQuery();

taskCollection = client.listTasks(client.getMailboxInfo().getTasksUri(), query);
iTasksCount = taskCollection.size();
for (int i = 0; i < iTasksCount; i++) {
    ExchangeTask task = (ExchangeTask) taskCollection.get_Item(i);
    // Process each queried task
}
```

- **المعلمات**:  
  - `selectedStatuses`: مصفوفة تحدد أي الحالات يجب تضمينها في مجموعة النتائج.
